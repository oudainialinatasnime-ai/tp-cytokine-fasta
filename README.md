# tp-cytokine-fasta
TP bioinformatique : analyse du FASTA UniProt cytokine en R
## Données
Fichier téléchargé depuis UniProt (recherche "cytokine", FASTA canonique)
le 10/11/2026 : 435 508 entrées.
Le fichier (97 Mo) n'est pas inclus dans ce dépôt.

## Utilisation
Modifier le chemin dans la variable `fichier` de analyse_fasta.R,
puis exécuter le script dans R.'
